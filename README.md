# Niall.M | Senior Webmaster & E-Commerce Developer Portfolio

A production-ready, high-converting portfolio website designed for a **Senior Webmaster & E-Commerce Developer**. Engineered with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons**.

Deployed with 100% independent asset architecture (all mockups and visual dashboards are procedurally generated via CSS & inline SVG, ensuring zero external asset dependencies and zero broken images).

---

## ⚡ Key Highlights & Architecture

- **Aesthetic**: Modern, high-end "Fintech / E-Commerce Studio" dark mode with a zinc/slate 950 foundation, glassmorphism (`backdrop-blur-md`), and emerald / electric indigo conversion accents.
- **Hero & Live Telemetry**: Value proposition headline, sub-second speed pitch, dual CTAs, Lighthouse CI live audit telemetry, and an interactive KPI stats ticker ($10M+ GMV, 99.99% Uptime, Sub-95ms API Latency, 100/100 Core Web Vitals).
- **Featured Case Studies (Procedurally Generated CSS/SVG Mockups)**:
  1. **Aura Luxury Apparel**: Headless fashion storefront (+42% mobile conversion, 0.8s TTFB, zero cart-drop rate).
  2. **Apex Gear Marketplace**: Multi-vendor B2B/B2C marketplace (120k+ orders/mo, automated split-payouts, MedusaJS + Stripe Connect).
  3. **Nova Botanics DTC**: High-volume DTC subscription platform (+28% retention, 1-click checkout flow, predictive rebill calendar).
  4. **Quantum Pay**: Global checkout & real-time fraud shield (99.98% clean transaction rate, -65% false declines, Cloudflare Workers).
- **Interactive Deep-Dive Modal**: Full architectural blueprints, bottleneck analysis, engineered solutions, and key business results for each case study.
- **Tech Stack Explorer**: Interactive module switcher across Frontend, Payments & Checkouts, Backend & Microservices, E-Com Platforms, and Analytics/CRO.
- **E-Commerce Performance Bento**: Interactive visual breakdown of WebP/AVIF media pipelines, edge routing, atomic CSS, and checkout anti-friction principles.
- **Interactive Project Inquiry**: Project scope & investment tier selector, client-side validated form, and 1-click clipboard triggers for Telegram and Email.

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript (strict mode)
- **Styling**: Tailwind CSS with custom theme extensions
- **Icons**: Lucide React
- **Animations**: CSS keyframes & Framer Motion

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

## 🌐 Deploy to Vercel (Zero-Config)

This repository is pre-configured for instant zero-config deployment to Vercel:

1. Push this repository to GitHub.
2. Import the project in the [Vercel Dashboard](https://vercel.com).
3. Select **Next.js** framework preset (detected automatically).
4. Click **Deploy**.
